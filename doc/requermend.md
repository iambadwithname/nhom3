# Midterm Requirements

## The class is divided into groups, with each group consisting of four students. Each group selects an image dataset, and the datasets must be different across groups. Using the selected dataset, each group performs either a classification or segmentation problem as follows:

1. [] Preprocess the data: clean, normalize, and augment the data.
2. [x] Design your own simple CNN model using convolutional, pooling, and fully connected layers to solve the given problem.
3. [x] Design your own complex CNN model using CNN blocks, convolutional, pooling, and fully connected layers to solve the given problem.
4. [] Design a CNN model using Transfer Learning/Fine-Tuning to perform the given task.
5. [x] Evaluate the models using appropriate performance metrics.
